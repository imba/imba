# Style Properties

Imba supports all regular css properties. For a full reference on all css properties we recommend visiting the MDN docs. There are some custom properties and shorthands added in Imba that are very valuable. There is also a configurable design system (inspired by Tailwind) built in. Among other things, this features non-standard values for `display`, `box-shadow`, `border-radius` and `transition-timing-function`, as well as `color` palettes. The custom `hue` property is especially useful.
