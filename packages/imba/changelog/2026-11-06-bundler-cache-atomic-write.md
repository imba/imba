Fix builds that fail when several imba processes start at the same time with one cache directory, for example job workers that restart together after a deploy. The bundler cache wrote each file in place, so another process could read the file while it was empty or partly written. That read failed with `Unexpected end of JSON input`. The cache then compiled the file again but returned `undefined`, and the build failed with `Cannot read properties of undefined (reading 'css')`.

The cache now writes each file to a temporary file and renames it into place, so a reader gets a complete file. If a cache file cannot be read, the cache compiles the source again and returns the result. A failed cache write now logs a warning and does not cause an unhandled promise rejection. You do not need to change any code.
