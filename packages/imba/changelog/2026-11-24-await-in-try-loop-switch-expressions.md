A loop, a `switch` or a `try` with `await` inside can now be part of a larger expression, for example `send(for item in items then await save(item))` or `(try await load!).length`. The compiler puts the loop, `switch` or `try` in an arrow function and calls that function at once. Before, that function was not async, so the file failed to load with `SyntaxError: Unexpected reserved word`. Now the function is async, and the code around it awaits the result: `(await (async ()=>{ … })())`.
