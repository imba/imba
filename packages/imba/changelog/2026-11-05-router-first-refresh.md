The router no longer sends a `change` event for its first refresh after the page load when the URL is the same. `Router#setup` ended with `refresh`, which only refers to the method, so the router had no current request when it started. The first refresh then sent `change` also when the URL did not change. For example, a `popstate` back to the same URL sent `change` when it was the first router event after the page load. An app that counts page views on `change` counted one extra page view.
