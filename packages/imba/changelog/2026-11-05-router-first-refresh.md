Fix an extra router `change` event after the page load. The first refresh of the router sent `change` also when the URL did not change, for example on a `popstate` back to the same URL. Later refreshes send `change` only when the URL changes. `Router#setup` referred to `refresh` but did not call it, so the router started without a current request. The setup now calls `refresh`, so the first refresh acts like the later ones.
