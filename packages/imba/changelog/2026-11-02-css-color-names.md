Color names in style values are handled more strictly. Named CSS colors keep their alpha: `c:red/50` and `linear-gradient(red/25, blue)` used to drop the `/50` and `/25`. A name that ends in a digit but is not a palette color, such as `ga:area1`, `animation-name:pop2` or `container-name:card2`, is no longer turned into a color. Used in a color property, such a name (for example a typo like `bg:night6`) is now a compile warning; it used to compile to black. Steps between 0 and 1, such as `gray05`, now mix the family's own 0 and 1 steps instead of a fixed blue.
