A bare `super` in a method now compiles to `super.method.apply(this, arguments)` instead of `super.method(...arguments)`. The spread built an iterator and an array on every call, which adds up in methods that run often, such as a field getter that calls its parent. The new form forwards exactly the same arguments, including those the method does not name, without allocating. The generated field initializer that calls up the class chain uses `apply` too, so creating an instance of a subclass allocates less.

Constructors still compile a bare `super` to `super(...arguments)`, since JavaScript requires that form there. A bare `super` in a getter or setter reads or assigns the parent's property as before. Output for TypeScript checking keeps the spread. You do not need to change any code.
