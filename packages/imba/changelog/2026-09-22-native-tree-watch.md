Watch project trees natively on macOS and Windows: one recursive `fs.watch` per root (the project, plus the package that owns each linked input outside it: the directory above its outermost `node_modules`, else the nearest `package.json`) instead of one chokidar `fs.watch` per file. chokidar 4+ has no FSEvents backend, so per-file watching cost one kqueue descriptor per file on macOS; a large project passed `OPEN_MAX` (10240), after which every reload's `cluster.fork` failed with `spawn EBADF` and the dev server died. Linux keeps chokidar, and `IMBA_WATCHER=chokidar` forces it elsewhere. `imbaconfig.json` gains `watch.ignore`, a gitignore-style list of paths the watcher never reports (`"watch": {"ignore": ["logs", ".verify"]}`; a bare name matches at any depth, a path containing a slash is anchored to the project root); `.git`, `.imba-cache`, `.cache`, `.DS_Store` and the build outdir are always ignored. The watcher no longer prints `add <path>` for every new file.
