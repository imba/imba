Fix a crash when an expression tag (`<(…)>`) returns an svg element. To reconcile the classes of the element, the runtime called `indexOf` on `className`, but on svg elements `className` is an `SVGAnimatedString`, which has no `indexOf`. The first reconcile also removed the classes that the svg element was created with. `SVGAnimatedString` now has an `indexOf` that reads `baseVal`, and svg elements read their initial classes from `className.baseVal`.
