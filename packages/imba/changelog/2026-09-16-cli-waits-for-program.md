Keep the `imba` CLI running until the program that it forked exits. The CLI forks the program when it runs one instance without watch mode. On `SIGINT`, it sent the signal to the program and then exited after 5 seconds, also when the program was still shutting down. A process manager such as systemd takes that exit as the end of the service and kills the program at once. The CLI now exits when the program exits, with the exit code of the program. A second `SIGINT` kills the program immediately and exits.
