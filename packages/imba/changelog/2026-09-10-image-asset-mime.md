Add a `mime` field to imported images. `import logo from './logo.png'` gives an asset with `url`, `type`, `width` and `height`, and now also `mime`, for example `'image/png'`. The bundler gets the format from the file content when it can, and else from the file extension. `mime` is `null` for a format that the bundler does not know (it knows png, apng, jpeg, gif, webp, avif, ico, bmp and svg).
