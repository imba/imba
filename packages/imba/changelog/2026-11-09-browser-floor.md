Raise the default browser targets for web, client and worker builds from `chrome88`, `edge79` and `safari15` to `chrome99`, `edge99`, `firefox97` and `safari15.4`. These are the first versions that support CSS cascade layers (`@layer`), which Imba's CSS is moving towards. Firefox was not in the list before, so esbuild did not lower syntax for it. To keep supporting older browsers, set `target` in the `base` options of your `imbaconfig.json`.
