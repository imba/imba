A runtime `hue` value works. `<div[hue:{kind} c:hue5]>` compiled `--hue0` through `--hue9` to text such as `VarOrAccess(kind)5`, so the hue colors resolved to nothing. The element now gets one variable per palette level when the value changes, so `hue5` and the other levels match what a static `hue:teal` gives, also in children and under modifiers. Values that are not palette names leave the levels unset.
