A plain number in an ease shorthand or longhand is now a time in milliseconds. `eo:0` was read as the name of an easing function and compiled to `--e_of: var(--ease-0,0)`, which made the shared `transition` invalid and turned off every transition on the element. `eod:0` set a duration of `0` without a unit, with the same result. `eo:0`, `ec:150`, `eod:0` and `ecw:20` now mean `0ms`, `150ms`, `0ms` and `20ms`.
