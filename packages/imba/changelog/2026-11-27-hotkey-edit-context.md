A hotkey no longer triggers while the focus is in an element with an [EditContext](https://developer.mozilla.org/en-US/docs/Web/API/EditContext_API), as for an input, a textarea or a contenteditable element. A code editor such as Monaco can take text input through an EditContext on an element without contenteditable. Before, a hotkey such as `space` or `<` triggered while a user typed in the editor. A hotkey with `.capture` still triggers there, as it does in a textarea.
