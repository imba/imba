Compile-time flags in front of an export declaration now work: `$node$ export const secret = 1`, `$node$ export def server-fn`, `$node$ export class Server` and `$node$ export default ...` are left out of browser builds, and `$web$ export ...` is left out of node builds. The flags used to be ignored, so the export was always included. Export lists and imports, as in `$node$ export {a}` and `$node$ import ...`, already worked this way.
