`animation` lists keep their keywords in every item. In `animation:rise 1s linear both, fade 1s linear both`, the second `both` was taken for an animation name and compiled to `var(--animation-both,both)`, because the keywords seen in the first item were still counted. An animation named with a single letter `l`, `c`, `h` or `a`, as in `animation:a 1s`, no longer crashes the compiler.
