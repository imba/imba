A `let` or `const` inside an `if $web$`, `if $node$` or other compile-time flag block no longer collides with a variable of the same name outside the block. These blocks are unwrapped into the enclosing code, so `let a = 5` followed by `if $web$` with `let a = 1` inside compiled to `let a = 5; let a = 1;`, and the file failed to load with `Identifier 'a' has already been declared`. A block whose declarations would clash with a variable, a parameter or an earlier unwrapped block now keeps its braces. Other blocks are still unwrapped, so imports, exports and declarations inside them stay at the top level of the module.
