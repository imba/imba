A plain element with `key=` outside a loop, such as `<div key=page>` directly in a template, is now inserted into the DOM. It used to be created without a parent and never inserted, so it was missing from the page; inside a loop, an `if` or for components `key=` already worked. The element now behaves like a keyed component: the same key keeps the element, a changed key replaces it in place, and an earlier key gets its old element back. Its children are memoized on the element, so a replaced element shows the new content.
