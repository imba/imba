Write the css rules that compiled stylesheets share once in a built css file. Every file that uses `ease` or a transform property such as `x`, `rotate` or `scale` gets its own copy of a helper rule that reads the variables. The rule for easing is about 1KB. Every file with enter or leave transitions also starts with the same two rules. `imba build` now joins the helper rules of a merged css file into one rule that lists all the selectors, and removes a rule when the same rule, with the same selectors and the same body, is written again further down. The css of four apps became 8% smaller, and 2% smaller gzipped.

This does not change which declaration wins for an element. A helper rule is not moved past a rule that could win over it, such as a `transform` or `transition` in a global rule with a selector of the same weight. A file with such a rule keeps a helper rule of its own. Helper rules inside `@media` are only joined with helper rules under the same `@media`.
