A bitwise set-if-changed operator on its own line compiles to valid JavaScript. `flags |=? mask` as a statement used to compile to `if ((flags & ($1 = mask)) == $1) false else {...}`, and JavaScript rejects that with `Unexpected token 'else'`, so the file did not load. Statements with `=?`, `|=?` and `~=?` now compile to the same conditional expression that these operators give in a condition or an assignment.
